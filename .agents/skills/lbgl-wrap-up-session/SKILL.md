# セッションの振り返りと文脈の抽出

会話を終了（またはクリア）する前に、次回の新しいセッション（会話）へスムーズに文脈を引き継ぐため、これまでの対話履歴全体を分析して情報を整理してください。

## 実行手順

1.  **対話履歴と既存コンテキストの分析**:
    これまでのユーザーとのやり取り、提案した内容、修正したコード、および合意した事項を振り返ります。
    また、現在の `books/lbgl-context.md` を読み込み、すでに記録されている内容を確認します。

2.  **情報の分類と抽出**:
    対話の中から以下の情報を抽出します。
    *   **進捗状況と今後の予定**: このセッション内で進めている作業の進捗と、次のセッションで行う作業の予定。
    *   **プロジェクトの前提情報・基本方針**: 対話の中で具体化されたニュアンスや、ターゲット層、ユーザーの目的など。
    *   **進捗と全体構成**: 現在どこまで作業が進んでいるか、プロジェクト全体の構造やアーキテクチャの割り切りなど。
    *   **新たに決まった暗黙のルール**: レビューやコーディングの中で新しく決まった特有の取り決め、用語の使い分け、書式ルールなど。

3.  **2つの形式での出力**:
    抽出した情報を以下の2つのセクションに分けてMarkdown形式でユーザーに提示してください。

    **① `lbgl-context.md` の更新提案**
    抽出した情報を踏まえ、既存の `books/lbgl-context.md` に対してどのような内容を追記・修正すべきか、更新内容（差分や追加テキスト）を提案してください。

    **② ルール・スキルへの追記提案**
    新たに決まった「AIのチェック基準」や「暗黙のルール」をリストアップします。これらはコンテキストファイルではなく、プロジェクトの `AGENTS.md` や `.agents/rules/`、既存の `SKILL.md` に直接反映すべきものとして具体的に提案してください。
