---
title: "4.9 while-then-else"
---

Python のちょっとおもしろい（と思っている）機能に、while 文の `else:` がつけられるというのがあります。途中で `break` しないで最後までループを実行したときに `else:` の節が実行されます。たとえばこんなコードなら `is_ok()` がすべて `True` であれば `OK` と出力されます。`is_ok()` が一度でも `False` になれば `NG` を出力してループを抜け、それで終わりです。

```py
    i = 0
    while i < 3:
        if not is_ok(i): print("NG", i); break
        i += 1
    else: 
        print("OK")
```

これ自分はわりと好きなんですけど世間的にはあまり評判よくない感じです。上のコードを `else:` 使わないでやろうとするとフラグを持たせたり関数に分けたりしないといけないんですよね。

評判のよくない理由はいろいろあるのかもしれませんが、`else` だとなんか反対の動きしそうな気がする、っていうのがひとつあると思います[^reconsider-at-python3]。`then` のほうが自然な気がするんですが Python には `then` っていうキーワードがなくてそうなっちゃったんじゃないかと想像しています。

[^reconsider-at-python3]: Python 2 → Python 3 のときにもなんとかしようよという議論があったそうです。

この方が自然ではないでしょうか？

```py
    i = 0
    while i < 3:
        if not is_ok(i): print("NG", i); break
        i += 1
    then:
        print("OK")
```

いやいや、それならむしろこう書けたら気持ちいいのでは？

```py
    i = 0
    while i < 3:
        if not is_ok(i): break
        i += 1
    then:
        print("OK")
    else:
        print("NG", i)
```

ということで Toil ではこんな風に書けるようにします[^as-promised]。文字列はまだ実装してませんが。`then` だったら while 式の値が `True` に、`else` だったら `False` になるということも自然に書けていることにご注目。

[^as-promised]: 前節で予告した『ちょっと違うやり方』がこれです。

```
    i := 0; while i < 3 do
        if not is_ok(i) then break end;
        i = i + 1
    then 
        print('OK'); True
    else
        print('NG', i); False
    end 
```

`break` で抜けた場合とそうでない場合が対称になるし `if-then-else-end` と統一感が出るし `break` したときしないときの `while` の値も自由に書けるしけっこういいのでは、という気がしています。タイピング量はちょっと増えますけど。

今まで `while` はループで最後に評価した式の値を返すことにしていましたがあれはやめます。たいていそういう仕様なんですが実はそんなに使い勝手よくないなあと思ってたので。何か値を返したければ明示的に Then 式を書いてください、ということで。Then 式が省略されていれば値は `None` とします。`break` したけど Else 式が省略されていた時も同様。

では実装行きます。

まずは `while` の AST に Then 式と Else 式を追加します。このとき、`then` や `else` が省略されていたら `None` を返すようにします。if 式のときと同じですね。

```diff py
class Parser:
     ...

     def _while(self):
         self._current_and_advance()
         cond_expr = self._expression()
         self._consume(Ident("do"))
         body_expr = self._expression()
+        then_expr = else_expr = None
+        if self._current_token() == Ident("then"):
+            self._current_and_advance()
+            then_expr = self._expression()
+        if self._current_token() == Ident("else"):
+            self._current_and_advance()
+            else_expr = self._expression()
         self._consume(Ident("end"))
-        return (Ident("while"), [cond_expr, body_expr])
+        return (Ident("while"), [cond_expr, body_expr, then_expr, else_expr])

     ...
```

それに合わせて `eval()` の `case` を修正したら・・・

`_while` で Then 式や Else 式を評価して値とします。

```diff py
-    def _while(self, cond_expr, body_expr, env):
+    def _while(self, cond_expr, body_expr, then_expr, else_expr, env):
-        val = None
         while self.eval(cond_expr, env):
             try:
-                val = self.eval(body_expr, env)
+                self.eval(body_expr, env)
             except ContinueException: continue
-            except BreakException: return None
+            except BreakException: return self.eval(else_expr, env)
-        return val
+        return self.eval(then_expr, env)
```

そんなにややこしい修正ではないと思います。

実行例です。

```py
    # Example

    print("While-then-else:")

    print(toil.ast(r""" while i < 3 do i = i + 1 end """))
    # -> (while, [(less, [i, 3]), (assign, [i, (add, [i, 1])]), None, None])
    print(toil.walk(r""" i := 1; while i < 3 do i = i + 1 end """))
    # -> None
    print(toil.walk(r""" i := 1; while i < 3 do break end """))
    # -> None
```

`then` も `else` もないとき。

```py
    print(toil.ast(r""" while i < 3 do i = i + 1 then i else 0 end """))
    # -> (while, [(less, [i, 3]), (assign, [i, (add, [i, 1])]), i, 0])
    print(toil.walk(r""" i := 1; while i < 3 do i = i + 1 then i else 0 end """))
    # -> 3
    print(toil.walk(r""" i := 1; while i < 3 do break then i else 0 end """))
    # -> 0
```

`then` も `else` もあるとき。

```py
    print(toil.walk(r""" i := 1; while i < 3 do i = i + 1 then i end """))
    # -> 3
    print(toil.walk(r""" i := 1; while i < 3 do break then i end """))
    # -> None

    print(toil.walk(r""" i := 1; while i < 3 do i = i + 1 else 0 end """))
    # -> None
    print(toil.walk(r""" i := 1; while i < 3 do break else 0 end """))
    # -> 0
```

どちらかだけあるとき。

どれも、`while` の条件を満たさなくなってループを抜けたときと、途中で `break` したときで想定通りの値を返しています。

```py
    print(toil.walk(r"""
        sum := 0; i := 1;
        while i < 4 do
            sum = sum + i;
            i = i + 1
        then sum end
    """)) # -> 6
```

すこしだけ実用的な `then` の使い方。`while ... end; sum` って書いてもおんなじことなんですけど、`while` が式で値を持つとしたら `while` 自体が値が返せた方が気持ちいい気がします。

```py
    print(toil.walk(r"""
        i := 0; while i < 4 do
            if i == 1 then i = 2; continue end;
            print(i);
            i = i + 1
        then i end
    """)) # -> 0\n2\n3\n4
```

`continue` は `then` や `else` には影響しません。

```py
    toil.walk(r"""
        i := 1; while i < 4 do
            j := 1; while j < 4 do
                if i == 2 and j == 2 then break end;
                print(i, j);
                j = j + 1
            else break end;
            i = i + 1
        end
    """)
    # -> "1 1\n1 2\n1 3\n2 1\n"
```

入れ子になったループで、内側のループから一気に外まで抜けたいときに自然に書けるのがすこし自慢です。

```py
    print(toil.walk(r""" while False do 1/0 then 3 else 4 end """)) # -> 3
```

ループ本体を一度も実行しなくても、`while` の条件を満たさなくて抜けたのなら `then` の値が返されます。
