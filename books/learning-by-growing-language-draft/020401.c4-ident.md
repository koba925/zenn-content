何をするかというと、識別子を表すための `Ident` クラスを導入します。これは、Toil で文字列型を扱えるようにするための準備です。

第 1 部では、変数名や `+`・`:=` などの演算子などを含む識別子をすべて Python の文字列（`str`）で表現していました。しかし、このまま Toil に `"foo"` のようなデータとしての文字列を導入しようとすると、AST の中に文字列があったとき、それが `foo` という名前の変数なのか `"foo"` という文字列なのか区別できなくなってしまいます。

そこで、識別子や記号などを表現するための専用の型として `Ident` クラスを作ります。識別子をすべて `Ident` オブジェクトにしておくことで、文字列と明確に区別できるようになります。識別子をそのままにしておいて文字列をたとえば `ToilStr` といったクラスで表すことによって区別することもできますが、数や `bool` のように、Python の値をそのまま Toil の値として使うことでシンプルな実装が可能になっていることもあり、文字列を `str` で表し、識別子のために別のクラスを定義する方を選びました。

Toil に文字列型を導入するのは少し後になりますが、これ以上変更箇所が多くならないうちにということでこのタイミングで導入します。

`Ident` の定義は以下の通りです。ファイルの先頭に追加してください。

```diff py
+class Ident:
+    __match_args__ = ("name",)
+
+    def __init__(self, name): self.name = name
+    def __hash__(self): return hash(self.name)
+    def __repr__(self): return self.name
+    def __str__(self): return self.name
+    def __eq__(self, other):
+        return isinstance(other, Ident) and self.name == other.name

 def is_ident_first(c): return c.isalpha() or c == "_"
 ...
```

`Ident` クラスは中に文字列 `name` を持っているだけのシンプルなクラスです。

元が文字列なので `Ident` を `str` のサブクラスにするというのも素直なやり方なのですが、サブクラスにしてしまうと `case str()` に `Ident` オブジェクトもマッチしてしまい、ちょっと書きづらくなってしまうのでサブクラスにはせず、独立したクラスとしました。そのため、一部の特殊メソッドを実装する必要があります。

`__init__()` では `name` という属性を定義しています。`name` は外から見えるパブリックな属性として使うため先頭にアンダースコアは付けません。

`__hash__()` を定義することにより辞書のキーとして使うことができるようになります。

`__repr__()` や `__str__()` では、`Ident` オブジェクトをどのように表示するかを決めています。`name` 属性をそのまま返しているので、`"foo"` という名前の `Ident` オブジェクトを表示すると `foo` とクォーテーションなしで表示されます。デバッグ中にはクォーテーションのありなしで識別子か文字列か区別できます。本来は `__repr__()` がより形式的で厳密な表示、`__str__()` は厳密さは多少落ちても人間が読みやすい表示、という使い分けなのですが Toil ではデバッグ出力時の見やすさ・コンパクトさを優先しました。

`__eq__()` では `==` で比較したときどのようにして同じかどうか判定するかを定義します。ここでは、まず比較対象が `Ident` であることを確かめてから `name` が同じかどうかを確認しています。

`__match_args__ = ("name",)` を定義することで、match 文で `case Ident(name):` のように中身の文字列を取り出せるようになっています。

これだけあれば識別子に対してやりたいことがカバーできています。説明は最低限にしましたが、詳しく知りたい方は節末のコラムをどうぞ。言語処理系の本筋とは関係ない部分でもあるので、あまり気にせず進んでも問題ないです。

では修正していきます。

ほとんどは `Ident()` で囲むだけですが、いくつか `Ident` を使った `case` のパターンについて説明しておきます。

```py

```

これは単純に値が `Ident("(")` と一致するかどうかを判断しています。

```py

```

値が `Ident` であるかどうかを判断するとともに、`Ident` オブジェクトから `name` 属性を取り出してくれます。ここではガード式の中で `name` を使っています。

ここでは `as` を使って、`Ident()` に一致したものに名前を付けています。`Ident(name)` が `name` を `Ident` から取り出しているのに対し、ここでは `Ident()` に一致した `Ident` オブジェクトそのものに `ident` という名前を付けていることに注意してください。

`Ident` クラスの実行例です。

```py
    print("Ident class:")
    print(Ident("aaa") == Ident("aaa")) # -> True
    print(Ident("aaa") == Ident("bbb")) # -> False
    print(Ident("aaa") == "aaa") # -> False

    print({Ident("aaa"): 2}[Ident("aaa")]) # -> 2
    print(Ident("aaa") in {Ident("aaa"): 2}) # -> True
    print(Ident("bbb") in {Ident("aaa"): 2}) # -> False
    print("aaa" in {Ident("aaa"): 2}) # -> False

    print(toil.scan(r""" a := 2 """)) # -> [a, :=, 2, $EOF]
    print(toil.ast(r""" a := 2 """)) # -> (define, [a, 2])

    print("aaa") # -> aaa
    print(repr("aaa")) # -> 'aaa'

    print([Ident("aaa")]) # -> [aaa]
    print(["aaa"]) # -> ['aaa']
```

`Ident` クラスでやりたいことはだいたいこんなところです。

`a := 2` のトークン列や AST の `print` 結果を見てください。`define` や `:=`、`a` がクォーテーションで囲まれていません。今後、Toil で文字列を扱うようになったときはクォーテーションで囲まれていれば文字列、囲まれていなければ識別子（`Ident`）であると見分けられます。これが `Ident` の `__repr__()` や `__str__()` をカスタマイズした目的です。ただしひとつ注意点があります。`print("aaa")` のように裸の文字列を `print` したときだけは文字列にクォーテーションがつきません（配列やタプルの中の文字列はクォーテーションで囲まれます）。たいていの場合は問題ないのですが、どうしても裸の文字列と識別子を表示で区別したいときは `repr()` で囲むなどして `repr` 形式で表示してください。

## コラム：Python の特殊メソッド

`Ident` クラスで定義した `__hash__()` や `__repr__()` のような、名前がふたつのアンダースコアで囲まれたメソッドを特殊メソッドと呼びます。これらを自作クラスに定義することで、Python のクラスや属性へのアクセス、`==`・`+` などの演算子の挙動などを相当程度カスタマイズできます。

`Ident` クラスで使った特殊メソッドについて詳しく知りたい方は Python 公式ドキュメントを見てみてください。「特殊メソッド名」という節になっていますが、`__match_args__` の説明もあります。
