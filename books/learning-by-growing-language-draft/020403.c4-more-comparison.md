まずは小手調べ。なんか足りない気がしてたに違いない組み込み関数や演算子を追加しましょう。`!=` と `>=` と `<=` です。

今までのやり方と変わらないので淡々と行きます。

組み込み関数を追加します。

ツリーウォーク式インタプリタに集中します、と言っておきながらこの節の変更は字句解析・構文解析・組み込み関数すべてツリーウォーク式・中間コード式の共通部分への変更なので中間コード式の方でも動いてしまいますので動かしておきましょう。テストコードも両方に追加しています。

```py
    # Example

    print("More comparison:")

    print(toil.walk(r""" 2 != 2 """)) # -> False
    print(toil.walk(r""" 2 != 3 """)) # -> True

    print(toil.walk(r""" 3 <= 2 """)) # -> False
    print(toil.walk(r""" 2 <= 2 """)) # -> True
    print(toil.walk(r""" 2 <= 3 """)) # -> True

    print(toil.walk(r""" 2 >= 3 """)) # -> False
    print(toil.walk(r""" 2 >= 2 """)) # -> True
    print(toil.walk(r""" 3 >= 2 """)) # -> True

    print(toil.run(r""" 2 != 2 """)) # -> False
    print(toil.run(r""" 2 != 3 """)) # -> True

    print(toil.run(r""" 3 <= 2 """)) # -> False
    print(toil.run(r""" 2 <= 2 """)) # -> True
    print(toil.run(r""" 2 <= 3 """)) # -> True

    print(toil.run(r""" 2 >= 3 """)) # -> False
    print(toil.run(r""" 2 >= 2 """)) # -> True
    print(toil.run(r""" 3 >= 2 """)) # -> True
```
