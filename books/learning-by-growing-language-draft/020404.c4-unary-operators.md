title: "4.4 単項演算子"
---

今までに作った演算子は二項演算子でした。今回は単項演算子を作ります。具体的には単項マイナス（`-2` における `-`。数字の符号を変える演算子で、引き算の `-` と区別するため「単項マイナス」と言います）や、否定（`not 2 == 2` の `not`）を作ります。演算子に項がひとつしかついてないので単項演算子といいます。項の後ろに演算子を置く後置演算子もありますが、Toil では前置演算子だけを作ります。

作り方のあらすじはそれほど変わりません。まずは組み込み関数を追加します。

```diff py
 class Interpreter:
     ...
 
     def _builtins(self):
         ...
         self._env.define(Ident("mod"), lambda args: args[0] % args[1])
+        self._env.define(Ident("neg"), lambda args: -args[0])

         ...
         self._env.define(Ident("greater_equal"), lambda args: args[0] >= args[1])
 
+        self._env.define(Ident("not"), lambda args: not args[0])

         self._env.define(Ident("print"), lambda args: print(*args))
         ...

    ...
```

`lambda` が配列 `args` で引数を取るようになっているので、引数がふたつでもひとつでも扱うことができます。ていねいにやるなら引数の数をチェックするところですが Toil ではチェックしないことにします。

`-` はすでにトークンとして扱っており、`not` は識別子として認識されますので今回は字句解析には変更は要りません。構文解析を修正します。

```diff py
class Parser:
     ...

     def _define_assign(self):
         return self._binary_right({
             Ident(":="): Ident("define"), Ident("="): Ident("assign")
-        }, self._comparison)
+        }, self._not)
+
+    def _not(self):
+        return self._unary({Ident("not"): Ident("not")}, self._comparison)
 
     def _comparison(self):
         ...

     ...

     def _mul_div_mod(self):
         return self._binary_left({
             Ident("*"): Ident("mul"), Ident("/"): Ident("div"),
             Ident("%"): Ident("mod")
-        }, self._call)
+        }, self._unaries)
+
+    def _unaries(self):
+        return self._unary({Ident("-"): Ident("neg")}, self._call)
 
     def _call(self):
         ...

```

`not` の優先順位は低めで、定義・代入と比較の間です。`a = not 2 == 2` と書いたら `2 == 2` の判定を行ってから否定して `a` に代入してほしいという気持ち。

単項マイナスの優先度は逆に高めで、かけ算・割り算・剰余と関数呼び出しの間です。`-add(2, 3) * 4` なら `2` と `3` を足して、マイナスにしてから `4` をかけたい。関数名が `_unaries()` になっているのは、後でここに単項演算子を追加する未来が見えているからです。

今回の主役は `_unary()` です。

```diff py
     def _binary_right(self, ops, sub_elem):
         ...
 
+    def _unary(self, ops, sub_elem):
+        if type(op := self._current_token()) is Ident and op in ops:
+            self._current_and_advance()
+            return (ops[op], [self._unary(ops, sub_elem)])
+        else:
+            return sub_elem()

     def _comma_separated_exprs(self, terminator): 
     ...
```

否定を例にとると、`ops` は `{Ident("not"): Ident("not")}` で `sub_elem` が `self._comparison` です。今見ているトークンが `not` だったら `(Ident("not"), [<式>])` という AST を返します。`<式>` の部分にはまた否定の式を書くことができます。そのため、`not not 2 == 2` のような式も書けます。今見ているトークンが `not` でなければ `self._comparison()` の結果を返すだけです。

実行例です。

```py
    # Example

    print("Unary operators:")

    print(toil.ast(r""" -2 """)) # -> (neg, [2])
    print(toil.walk(r""" -2 """)) # -> -2

    print(toil.ast(r""" --2 """)) # -> (neg, [(neg, [2])])
    print(toil.walk(r""" --2 """)) # -> 2

    print(toil.ast(r""" 3--2 """)) # -> (sub, [3, (neg, [2])])
    print(toil.walk(r""" 3--2 """)) # -> 5

    print(toil.ast(r""" -add(2, 3) * 4 """)) # -> (mul, [(neg, [(add, [2, 3])]), 4])
    print(toil.walk(r""" -add(2, 3) * 4 """)) # -> -20

    print(toil.ast(r""" not 2 == 2 """)) # -> (not, [(equal, [2, 2])])
    print(toil.walk(r""" not 2 == 2 """)) # -> False

    print(toil.ast(r""" not not 2 == 2 """)) # -> (not, [(not, [(equal, [2, 2])])])
    print(toil.walk(r""" not not 2 == 2 """)) # -> True

    print(toil.ast(r""" a := not 2 == 2 """)) # -> (define, [a, (not, [(equal, [2, 2])])])
    print(toil.walk(r""" a := not 2 == 2 """)) # -> False
```

C や JavaScript のように `--` という演算子はありません。`--2` は `-(-2)` と解釈され AST では `(neg, [(neg, [2])])` となる一方、`3--2` は `3 - (-2)` と解釈され AST は `(sub, [3, (neg, [2])])` となります。どちらも正しい式です。
