title: "4.7 return"

次は、関数の途中で値を返す `return` を実装します。

まず文法ですが、ふつうの関数の形、つまり `return(2)` のように書くことにします。カッコを書かないでいいようにすることもできますがまあちょっとした手抜きです。その代わり、特に値を返す必要がない場合は `return` とカッコを省略できることにします。この場合は何も返さないというわけではなく、`None` を返します。

次は実装について。`if` は Python の `if` で、`while` は Python の `while` でほとんどそのまま実装できたし、`return` もそんな感じで書けるんじゃない？と思ったかもしれません。わたしもそう思ったんですが、`return` は実は意外とイレギュラーなやつでそうはいかないのです。

たとえば以下のようなコードを評価するとします。`n` が `0` だったら関数の評価中だけど打ち切って `0` を返す、そうでなければ次に進んで `1` を返すということですね。

```
def foo(a) do
    if n == 0 then return(0) end;
    1
end

foo(0)
```

`foo(0)` のときの `Evaluator.eval()` の動きを思い浮かべてみましょう。`eval()` は本当は AST を受け取るんですがそこは忘れてふわっといきます。 `eval()` が `foo(0)` という式を評価しようとするとこんな感じで `Evaluator` のメソッドが次々と呼ばれていきます。

```
eval(foo(0))
  _op(foo, [0])
    eval(if 0 == 0 then return(0) end; 1)
      _seq([if 0 == 0 then return(0) end, 1])
        eval(if 0 == 0 then return(0) end)
          _if(0 == 0, return(0), None)
            eval(return(0))
```

`eval(return(0))` している途中で `return 0` を実行したとしても普通に `_if()` に戻るだけで、`_if()` が終わった後 `_seq()` が次の式である `1` の評価に進んでしまいます。これではいけません。

ここでは、`eval(return(0))` を評価したら、途中をすっ飛ばしていきなり `_op()` に戻り、無理やり `0` を返させる、という少々乱暴な方法を取ります。

そんなことできましたっけ？

できます。例外を使います。`_op()` で関数本体を実行するコードを try 文に入れてやり、`return` に出会ったら例外を上げてやります。そうすると途中をすっ飛ばして `_op()` に戻ってきます。例外に値をつけておけば `try` に戻ったときにそれを取り出すこともできます。

あとは書きながら見ていきましょう。

Python で `a = 0` のとき `1/a` を計算したら `ZeroDivisionError` になるのでこれを `try-except` で拾ってプログラムが止まらないようにする、といった普通の例外の使い方はご存じのものとします[^exception-tutorial]。ここではそういう用途ではないので、`ReturnException` という自前の例外を作って他の例外と区別できるようにし、関数の値を持っておくための `val` という属性を持たせます。

[^exception-tutorial]: 例外になじみのない方は https://docs.python.org/ja/3/tutorial/errors.html をご覧ください。

```diff py
 class Environment:
     ...

+class ReturnException(Exception):
+    def __init__(self, val: Value = None) -> None: self.val = val

 class Evaluator:
     ...
```

`return` が出てきたら例外を上げる処理です。

```diff py
 class Evaluator:
     def eval(self, expr: Expr, env: Environment) -> Value:
         match expr:
             case None | bool() | int(): return expr
+            case Ident("return"): raise ReturnException(None)
             case Ident() as ident: return env.val(ident)
             case (Ident("func"), [params, body_expr]):
                 return (Ident("closure"), [params, body_expr, env])
+            case (Ident("return"), args):
+                raise ReturnException(self.eval(args[0], env))
             case (Ident("scope"), [body_expr]):
                 return self.eval(body_expr, Environment(env))
             ...
```

`case Ident("return")` はただ `return` と書かれたときに対応し、このときは `None` を `val` として `ReturnException` を送出します。例外を自分で送出するには raise 文を用います。

`case (Ident("return"), args)` は `return(2)` のように書かれた場合で、ひとつめの引数の位置にある式を評価し、それを `val` として `ReturnException` を送出します。引数の数があっているかどうかはチェックしていません。

続いて、送出された `ReturnException` を受け取って処理する箇所です。

```diff py
     ...

     def _op(self, op_expr, args_expr, env):
         ...
         match op_val:
             case f if callable(f): return f(args_val)
             case (Ident("closure"), [params, body_expr, closure_env]):
                 new_env = Environment(closure_env)
                 new_env.bind(params, args_val)
-                return self.eval(body_expr, new_env)
+                try:
+                    return self.eval(body_expr, new_env)
+                except ReturnException as e: return e.val
             case _:
                 assert False, f"Invalid operator @ _op(): {op_val}"

 class Compiler:
     ...
```

関数の中にいないときに `return` するのは普通はエラーですが、Toil は `2 + 3` を評価すれば終了コード 5 が返る言語ですので、関数の外で `return(2 + 3)` と書いたらプログラムをそこで終わって終了コード 5 を返すようにしましょう。`exit(2 + 3)` と同じようなものです。

関数の外にいるので、`Evaluator._op()` の `try` にはひっかからずに `Evaluator.eval()` も抜けて `Interpreter.eval()` まで戻ってきますのでここで同じように except で拾って値を返しましょう。

```diff py
class Interpreter:
     ...

     def ast(self, src: str) -> Expr:
         return self.parse(self.scan(src))
 

     def eval(self, expr: Expr) -> Value:
-        return Evaluator().eval(expr, self._env)
+        try:
+            return Evaluator().eval(expr, self._env)
+        except ReturnException as e: return e.val
 
     def walk(self, src: str) -> Value:
         return self.eval(self.ast(src))

     ...
```


```py
    # Example

    print("Return:")

    print(toil.ast(r""" return """)) # -> return
    print(toil.walk(r""" return; 3 """)) # -> None
    print(toil.ast(r""" return(2) """)) # -> (return, [2])
    print(toil.walk(r""" return(2); 3 """)) # -> 2
```

AST の確認と、関数の外からの `return` のテストです。ちゃんと途中で終わっています。

```py
    toil.walk(r"""
        def fib_rec(n) do
            if n == 0 then return(0) end;
            if n == 1 then return(1) end;
            fib_rec(n - 1) + fib_rec(n - 2)
        end
    """)
    print(toil.walk(r""" fib_rec(0) """)) # -> 0
    print(toil.walk(r""" fib_rec(1) """)) # -> 1
    print(toil.walk(r""" fib_rec(6) """)) # -> 8
```

再帰でフィボナッチ数を求めるコードが `return` を使える形なので書き換えてみました。この場合は `elif` を使う形の方がスジがいい気がしますがテストのために。

```py
    toil.walk(r"""
        def is_prime(n) do
            if n < 2 then return(False) end;
            i := 2;
            while i * i <= n do
                if n % i == 0 then return(False) end;
                i = i + 1
            end;
            True
        end
    """)
    print(toil.walk(r""" is_prime(1) """)) # -> False
    print(toil.walk(r""" is_prime(2) """)) # -> True
    print(toil.walk(r""" is_prime(4) """)) # -> False
    print(toil.walk(r""" is_prime(7) """)) # -> True
    print(toil.walk(r""" is_prime(15) """)) # -> False
```

素数かどうかを求めるプログラムです。2 で割った余りから始めて、3・4・5・・・と割っていき、割り切れたら素数ではないのでその場で関数を抜けて `False` を返します。

例外の仕組みをつかった `return` の実装でした。
