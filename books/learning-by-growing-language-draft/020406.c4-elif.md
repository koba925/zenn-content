title: "4.6 elif"
---

`if-then-else-end` を入れ子にすることで `elif` を回避してきましたが、そろそろ `elif` を導入しましょう。`if-then-else-end` で書けていたということは構文糖衣で作れるということです。

ついでに、else 節を省略できるようにもします。Toil では `if` も式なので、else 節がなかったからと言って何も返さないわけにはいきません。条件が偽なのに else 節がない場合は `None` を返すことにします。

`if-then-elif-else-end` や `if-then-end`、合わせ技で `if-then-elif-end` というパターンもあり得ます。これまでの `if` は、 `then` が来て式を読んだら次は `else` と決まっていましたが、今度は `elif` が来るかもしれないし、`end` が来るかもしれないということになりました。

```diff py
class Parser:
     ...

     def _if(self):
         self._current_and_advance()
         cond_expr = self._expression()
         self._consume(Ident("then"))
         then_expr = self._expression()
-        self._consume(Ident("else"))
-        else_expr = self._expression()
-        self._consume(Ident("end"))
+        if self._current_token() == Ident("elif"):
+            else_expr = self._if()
+        elif self._current_token() == Ident("else"):
+            self._current_and_advance()
+            else_expr = self._expression()
+            self._consume(Ident("end"))
+        else:
+            else_expr = None
+            self._consume(Ident("end"))
         return (Ident("if"), [cond_expr, then_expr, else_expr])

    ...
```

決め打ちで `self._consume(Ident("else"))` していたところを、現在のトークンを見て処理を分岐しています。

`else` だったら今までどおりです。

`end` だったら else 節に `None` と書いてあったフリをします。これで else 節がなくて条件が真でない場合は `None` が返りますね。

`elif` だったときがミソです。めんどくさそうな気がしたかもしれませんが（実際ちゃんと理解するにはきちんとコードを追っていかないといけませんが）コード上は `else_expr = self._if()` で済んでしまいます。

`if True then 2 elif True then 3 end` を例にとり、`elif` と else 節の省略をまとめて見ていきましょう。

`_if()` が呼ばれると `cond_expr` が `True`、`then_expr` が `2` の状態で `elif` の処理に入り、`_if()` を再帰的に呼び出します。この呼び出しは `elif True then 3 end` の部分を処理します。`_current_and_advance()` で `elif` を読み飛ばし、`cond_expr` が `True`、`then_expr` が `3`、`else_expr` が `None` となり、`(Ident("if"), [True, 3, None])` を返します。呼び出し側の `_if()` に戻り、`else_expr` が `(Ident("if"), [True, 3, None])` になるので `return (Ident("if"), [cond_expr, then_expr, else_expr])` で `(Ident("if"), [True, 2, (Ident("if"), [True, 3, None])])` が返されます。

`_if()` の冒頭で `if` を読み飛ばす部分を `self._current_and_advance()` と書いているのもちょっとしたミソで、もし `self._consume(Ident("if"))` と `if` 決め打ちで `_consume` すると `elif` の時にエラーになってしまいます。

これは、`if` を入れ子にして `if True then 2 else if True then 3 else None end end` と書いた時と同じ AST になっています。これでやりたかったことができたことになります。

いろんなパターンで動かしてみます。目がチカチカしますがどういうパターンのテストをしているかよく見てください。`if True then 2 elif True then 3 end` と `if True then 2 else if True then 3 else None end end` が同じ AST を返しているところも。

```py
    # Example

    print("Elif and omitting else clauses:")

    print(toil.ast(r""" if True then 2 end """))
    # -> (if, [True, 2, None])
    print(toil.walk(r""" if True then 2 end """))
    # -> 2

    print(toil.ast(r""" if False then 2 end """))
    # -> (if, [False, 2, None])
    print(toil.walk(r""" if False then 2 end """))
    # -> None

    print(toil.ast(r""" if True then 2 else 3 end """))
    # -> (if, [True, 2, 3])
    print(toil.walk(r""" if True then 2 else 3 end """))
    # -> 2

    print(toil.ast(r""" if False then 2 else 3 end """))
    # -> (if, [False, 2, 3])
    print(toil.walk(r""" if False then 2 else 3 end """))
    # -> 3

    print(toil.ast(r""" if True then 2 elif True then 3 end """))
    # -> (if, [True, 2, (if, [True, 3, None])])
    print(toil.walk(r""" if True then 2 elif True then 3 end """))
    # -> 2

    print(toil.ast(r""" if True then 2 else if True then 3 else None end end"""))
    # -> (if, [True, 2, (if, [True, 3, None])])
    print(toil.walk(r""" if True then 2 else if True then 3 else None end end"""))
    # -> 2

    print(toil.ast(r""" if False then 2 elif True then 3 end """))
    # -> (if, [False, 2, (if, [True, 3, None])])
    print(toil.walk(r""" if False then 2 elif True then 3 end """))
    # -> 3

    print(toil.ast(r""" if False then 2 elif False then 3 end """))
    # -> (if, [False, 2, (if, [False, 3, None])])
    print(toil.walk(r""" if False then 2 elif False then 3 end """))
    # -> None

    print(toil.ast(r""" if False then 2 elif True then 3 else 4 end """))
    # -> (if, [False, 2, (if, [True, 3, 4])])
    print(toil.walk(r""" if False then 2 elif True then 3 else 4 end """))
    # -> 3

    print(toil.ast(r""" if True then 2 elif True then 3 else 4 end """))
    # -> (if, [True, 2, (if, [True, 3, 4])])
    print(toil.walk(r""" if True then 2 elif True then 3 else 4 end """))
    # -> 2

    print(toil.ast(r""" if False then 2 elif False then 3 else 4 end """))
    # -> (if, [False, 2, (if, [False, 3, 4])])
    print(toil.walk(r""" if False then 2 elif False then 3 else 4 end """))
    # -> 4

    print(toil.ast(r"""
        if False then
            2
        elif False then
            3
        elif True then
            4
        else
            5
        end
    """)) # -> (if, [False, 2, (if, [False, 3, (if, [True, 4, 5])])])
    print(toil.walk(r"""
        if False then
            2
        elif False then
            3
        elif True then
            4
        else
            5
        end
    """)) # -> 4

    # print(toil.walk(r""" if True 2 end """)) # -> Expected then
    # print(toil.walk(r""" if True then 2 """)) # -> Expected end
    # print(toil.walk(r""" if True then 2 3 end """)) # -> Expected end
    # print(toil.walk(r""" if True then 2 else 3 """)) # -> Expected end
    # print(toil.walk(r""" if False then 2 elif True 3 end """)) # -> Expected then
    # print(toil.walk(r""" if False then 2 elif True then 3 """)) # -> Expected end

```

これでインデントを深くせずに複数の条件判断を並べられるようになりました。

if 文はいったんこれで完成です。しばらくは制御構造の強化を続けます。
