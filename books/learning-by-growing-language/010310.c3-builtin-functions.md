title: "3.10 組み込み関数"
---

`add(2, 3)` は今までこのようなコードにコンパイルされていました。このように、基本的な演算を命令として仮想マシンに組み込むのは普通のやり方です。

```py
 0: ('const', 2)
 1: ('const', 3)
 2: ('add',)
 3: ('halt',)
```

Toil では、このような形で演算を仮想マシンに組み込むのはやめて、「組み込み関数を呼ぶ」形で基本的な演算を実装します。`add(2, 3)` はこんなコードになります。

```py
 0: ('const', 2)
 1: ('const', 3)
 2: ('get', 'add')
 3: ('call', 2)
 4: ('halt',)
```

`('get', 'add')` という命令では、`add` に紐づいた値、つまり `_builtins()` で定義した `lambda args: args[0] + args[1]` をスタックに積みます。次の `('call', 2)` はスタックの最上位にある値を関数とし、続く 2 個の値を引数として関数を呼び、関数が返した値をスタックに積みます。これで組み込み関数が呼べたことになります。

`Compiler` の修正から見ていきましょう。

```diff py

         ...
 
+    def _op(self, op_expr, args_expr):
+        for arg in args_expr: self._expression(arg)
```

`(op_expr, args_expr)` という形の式だったら関数と見て、

```py
        for arg in args_expr: self._expression(arg)
```

引数の式の分だけ `_expression()` を繰り返し呼び、値をスタックに積みます。


```py
        self._expression(op_expr)
```

さらにその上に関数を積みます。「関数を積む」っていうとなんだか見慣れなくてなんだこれってなるかもしれませんが、`2 + 2` を計算して `4` を積む、というのと変わりありません。丁寧に書くと「`op_expr` には関数を表す式が入っているはずなので、式をコンパイルして（関数であるはずの）値をスタックに積む中間コードを出力する」です。

```py
        self._emit("call", len(args_expr))
```

最後に `call` します。仮想マシン側はいくつ引数が積まれているかわからないので、`call` の側から教えてあげるためにオペランドに引数の長さを入れています。

仮想マシンには `call` 命令を追加します。



スタックの一番上には関数が入っているのでまずそれを取り出します。次にオペランドに指定された数だけ引数を取り出しますが、取り出したままだと逆順なのでひっくり返してやります。`list(reversed(` としているのは、`reversed()` が配列ではなくイテレータを返すため、あらためて配列にしてやる必要があるからです[^reversed-more-details]。そうして関数に引数を与え、返された値をスタックに積みます。

[^reversed-more-details]: 詳しくは https://docs.python.org/ja/3/library/functions.html#reversed や https://docs.python.org/ja/3/glossary.html#term-iterator を参照ください。

`[self._stack.pop() for _ in range(nargs)]` はリスト内包表記で、 `nargs` 回だけ `self._stack.pop()` を実行し、その結果を配列にしたものです。普通は `for` のあとに変数名を書きますが、変数の使いどころがないので `_` にしています。`range()` を正確に説明しようとすると意外と大変なので、`range(3)` は 0、1、2 のように 3 つの要素を返してくれる、`for i in range(3)` なら `i` が 0、1、2 で 3 回実行する、`for _ in range(3)` なら 0 とか 1 とか具体的な数は無視してとにかく 3 回実行する、くらいに思っておいてください[^range-more-details]。

[^range-more-details]: 詳しくは https://docs.python.org/ja/3/library/stdtypes.html#range や https://docs.python.org/ja/3/library/stdtypes.html#typesseq を参照ください。

実行例です。

```py
    print("Built-in functions:")

    print(toil.ast(r""" add(2, 3) """))
    # -> ('add', [2, 3])
    print_code(toil.code(r""" add(2, 3) """))
    # ->   0: ('const', 2)
    # ->   1: ('const', 3)
    # ->   2: ('get', 'add')
    # ->   3: ('call', 2)
    # ->   4: ('halt',)
    print(toil.run(r""" add(2, 3) """)) # -> 5

    print(toil.run(r""" 2 + 3 """)) # -> 5
    print(toil.run(r""" 3 - 2 """)) # -> 1
    print(toil.run(r""" 2 * 3 """)) # -> 6
    print(toil.run(r""" 6 / 3 """)) # -> 2
    print(toil.run(r""" 7 % 3 """)) # -> 1

    print(toil.run(r""" 2 == 2 """)) # -> True
    print(toil.run(r""" 2 == 3 """)) # -> False

    print(toil.run(r""" 2 < 2 """)) # -> False
    print(toil.run(r""" 2 < 3 """)) # -> True

    print(toil.run(r""" 2 > 2 """)) # -> False
    print(toil.run(r""" 3 > 2 """)) # -> True

    toil.run(r""" print() """) # -> (empty line)
    toil.run(r""" print(2) """) # -> 2
    toil.run(r""" print(2, 3) """) # -> 2 3

    toil.run(r""" print(2 + 3 == 5) """) # -> True

    print(toil.run(r""" myadd := add; myadd(2, 3) """)) # -> 5

    # toil.run(r""" not_defined() """) # -> Undefined variable
```

ひととおりの組み込み関数を試していますがどれも `add` と同じです。`print` だけ任意の数の引数を取れるので、引数が 0 個、1 個、2 個の場合について試しています。
