これからインタプリタに機能を足していきますがまずは小手調べとして、字句解析時点でソースコードの空白やコメントをスキップするようにします。字句解析で空白やコメントを捨ててしまうことで、構文解析以降はそれらのことを考えなくてよくなり、本来の仕事に集中できます。字句解析→構文解析→評価と段階を分けて作る効果がこういうところに出てきます。

```diff py

         while (c := self._current_char()) != "$EOF":

+                case c if c.isspace(): self._advance()

                 case c if c.isdecimal(): self._number()

         return self._tokens

+

             ...
```

```py
                case c if c.isspace(): self._advance()
```

読んだ文字が `isspace()` だったらただ現在位置をひとつ進めます。`isspace()` はタブ（`"\t"`）や改行（`"\n"`）も空白とみなすので、それらも無視されます。ループするので、空白以外の文字が現れるまでこの処理が繰り返されることになります。

続いて、

```py
                case "#": self._comment()
                 ...

    def _comment(self):
        while self._current_char() not in ("\n", "$EOF"):
            self._advance()
```

`"#"` が出てきたらそこから行末またはソースコード末尾までをコメントとみなし、読み飛ばします。

実行例です。

```py
    print("Whitespaces:")
    print(toil.walk(r""" 2 """))  # -> 2
    print(toil.walk(r"""
        2
    """))  # ->  2

    # print(toil.walk(r""" """))  # -> Invalid token
    # print(toil.walk(r""" 2 34 """))  # -> Extra token

    print("Comment:")

    print(toil.walk(r""" 2 # Comment """))  # -> 2
    print(toil.walk(r"""
        # Comment
        2
        # Comment
    """))  # -> 2
```

トリプルクォートを使うことで、複数行のコードも書けています。なんかちょっとソースコードに見えてきましたね。エラーの出方も確認しておいてください[^coverage]。

[^coverage]: 前節で `walk()` ではできないと書いた `toil.parse([2, 34, "$EOF"])` に相当するテストが、空白で区切って複数の数を書けるようになったのでできるようになりました。
