title: "6.2 分割代入"
---

この節では、前節で導入した配列パターンのマッチを代入でも使えるようにします。Python だとアンパック代入と言って `[a, b] = [2, 3]` と書くようなものです。分割代入（Destructuring assignment）や構造化代入（Destructuring bind）と呼ぶ言語もあります[^inconsistent-translation]。`a, b = 2, 3` はタプルの略記を使った書き方で `(a, b) = (2, 3)` と同じ意味です。Toil の配列やタプルにはそういう略記法はないのでちゃんと？ `[]` を使って配列として書かないといけません。

[^inconsistent-translation]: Destructuring を分割と言ったり構造化と言ったり、逆に Assignment も Bind も代入と訳したり一貫性がない感じがしますが、ひとりで訳しているわけでもないのでしかたないんでしょうね。私はなんとなく Destructuring bind と言うのがカッコよく感じたのでタグ名にしました。

`Evaluator` で `define` の処理を変更します。

```diff py
 class Evaluator:
     def eval(self, expr: Expr, env: Environment) -> Value:
         match expr:
             ...
             case (Ident("scope"), [body_expr]):
                 return self.eval(body_expr, Environment(env))
-            case (Ident("define"), [Ident() as ident, expr]):
-                return env.define(ident, self.eval(expr, env))
+            case (Ident("define"), [pat_expr, val_expr]):
+                return self._define(pat_expr, val_expr, env)
             case (Ident("assign"), [left_expr, right_expr]):
             ...
 
+    def _define(self, pat_expr, val_expr, env):
+        val = self.eval(val_expr, env)
+        env.bind(pat_expr, val)
+        return val

     def _assign(self, left_expr, right_expr, env):
         ...
```

基本的には `env.define()` を `env.bind()` に変更しているだけなんですが、`bind()` が値を返さないので、値をとっておいてそれを返すようにしています。`eval()` を肥大化させないようにメソッドに切り出しました。

これでできあがりです。実行例に進みます。

```py
    # Example

    print("Destructuring bind:")

    print(toil.ast(r""" [a, b] := [2, 3] """))
    # -> (define, [[a, b], [2, 3]])
    print(toil.walk(r""" [a, b] := [2, 3] """)) # -> [2, 3]
    toil.walk(r""" print(a, b) """) # -> 2 3
```

AST、評価結果ともに想定通りです。

```py
    print(toil.walk(r""" [a, b] := [b, a] """)) # -> [3, 2]
    toil.walk(r""" print(a, b) """) # -> 3 2
```

分割代入と言えばこれ、という入れ替え（swap）の処理です。もし単に `a := b; b := a` という処理を行っているだけだと `[3, 3]` という結果になってしまうのですが、実際にはいったん `[b, a]` から `[3, 2]` という値を作り、その値から `[a, b]` に値を設定しているので正しく入れ替えが行われます。

とここで白状しておきますが、分割代入が一見シンプルにできているのは実のところ Toil の `define` の（若干手抜きな）仕様のおかげだったりします。`[a, b] := [b, a]` という式は `a`・`b` という変数がすでに存在するのが前提ですが、本来 `define` は新しく変数を定義するものなので厳密に実装すればこれはエラーになります。`define` が変数が定義済みでもかまわず変数の値を上書きするという仕様のおかげで変数が定義済みかどうか考えないで済んでいるのです[^also-assign]。

[^also-assign]: すでに配列要素への値の代入を実装してやや複雑化している `assign` にパターンマッチを入れる必要がなくなっているのもラッキーです。

```py
    toil.walk(r""" [a, _, _] := [2, 3, 4] """)
    toil.walk(r""" print(a, _) """) # -> 2 4
```

ということでこういうこともできます。`_` は一見特殊な意味を持つようですがちょっと変わった名前というだけのただの変数です[^even-as-a-parameter]。左辺に 2 回登場しますが、まんなかの `_` にいったん設定された値（`3`）が右の `_` の値（`4`）で上書きされています。これも一見手抜きのようですが実は Python と同じ動きです。

[^even-as-a-parameter]: なので関数の引数に使っても合法なんですが、使い方として不自然なのでこの節で紹介しました。

```py
>>> a, _ = 2, 3
>>> a
2
>>> _
3
>>> a, _, _ = 2, 3, 4
>>> a
2
>>> _
4
```

続けます。

```py
    toil.walk(r""" [a, [b, c]] := [2, [3, 4]] """)
    toil.walk(r""" print(a, b, c) """) # -> 2 3 4
```

```py
    print(toil.walk(r""" a := 2 """)) # -> 2
    print(toil.walk(r""" a """)) # -> 2
```

エラーの確認。

```py
    toil.walk(r""" [] := [] """) # Legal
```

これはエラーにはなりません。何もしませんが。

```py
    toil.walk(r"""
        def fib_iter(n) do
            a := 0; b := 1;
            while n > 0 do
                # tmp := b; b = a + b; a = tmp;
                [a, b] := [b, a + b];
                n = n - 1
            then a end
        end
    """)
    print(toil.walk(r""" fib_iter(0) """)) # -> 0
    print(toil.walk(r""" fib_iter(1) """)) # -> 1
    print(toil.walk(r""" fib_iter(6) """)) # -> 8
```

分割代入を実装したおかげで一時変数を使わずにフィボナッチの計算もできるようになりました。

さて今回はもう 1 つやりましょう。for 式の分割代入です。`for [i, j] in [[2, 3], [4, 5]] do` のように書けば `i` や `j` に分割代入されるというもので意味合いは全く同じです。

```diff py
 class Evaluator:
     ...

     def _for(self, var_expr, coll_expr, body_expr, then_expr, else_expr, env):
         coll_val = self.eval(coll_expr, env)
         assert isinstance(coll_val, (list, tuple, str)), \
             f"Invalid loop target @ _for(): {coll_val}"
         for val in coll_val:
             try:
-                env.define(var_expr, val)
+                env.bind(var_expr, val)
                 self.eval(body_expr, env)
             except ContinueException: continue
             except BreakException: return self.eval(else_expr, env)
         return self.eval(then_expr, env)
```

`define` を `bind` に変えただけですが・・・

```py
    print(toil.walk(r"""
        a := []; for [i, j] in [[2, 3], [4, 5]] do a.push([i, j]) then a end
    """)) # -> [[2, 3], [4, 5]]

    print(toil.walk(r"""
        a := [];
        keys := ["a", "b", "c"];
        values := [2, 3, 4];
        for [k, v] in zip(keys, values) do a.push([k, v]) then a end
    """)) # -> [['a', 2], ['b', 3], ['c', 4]]
```

ちゃんと動きました。`zip()` との相性も OK です。
