---
title: "6.4 rest パターン"
---

Python で `def foo(*a):` などと関数を定義すると、`foo()` とも `foo(2)` とも `foo(2, 3)` とも呼べて引数が `a` に配列として渡されるというのがありますね。`def foo(a, *b):` であれば最低 1 つの引数が必要で残りが `b` に渡されます。あれをやります。

`*` はすでにトークンとして扱われることになっているので字句解析は修正不要です。

次に `*a` という構文を通すように構文解析に手を入れます。これは単項演算子として扱うことにすればよいので `_unaries()` に `*` を追加してやります。

```diff py
 class Parser:
     ...

     def _unaries(self):
-        return self._unary({Ident("-"): Ident("neg")}, self._call_index_dot)
+        return self._unary({
+            Ident("-"): Ident("neg"), Ident("*"): Ident("*")
+        }, self._call_index_dot)

     ...
```

AST では `neg` のような名前を付けず `*` のままにしています。これにはあまり深い意味は込めていなくて、関数でもないのでそのままにしておこう、くらいの感覚です。これで `*a` は `(*, [a])` という AST になります。

今回の主役は `_bind_list()` です。

```diff py
 class Environment:
     ...

     def _bind_list(self, pattern, value):
-        if len(pattern) != len(value): return False
-        for sub_pat, sub_val in zip(pattern, value):
-            if not self.bind(sub_pat, sub_val): return False
-        return True
+        for i, sub_pat in enumerate(pattern):
+            match sub_pat:
+                case (Ident("*"), [rest_pat]):
+                    return i == len(pattern) - 1 and self.bind(rest_pat, value[i:])
+                case _:
+                    if i >= len(value) or not self.bind(sub_pat, value[i]):
+                        return False
+        return len(pattern) == len(value)

     ...
```

やりたいことの大枠は変わっていないのですが、パターン・値の要素を 1 つずつのペアとして扱うだけでは済まなくなったため全体の書き方が変わっています。要するに今何番目の要素を見ているかを把握しておきたいので、`for i, sub_pat in enumerate(pattern)` で番号とパターンの要素をひとつずつ取り出しています。

`(*, [a])` のようなパターンの場合は `i == len(pattern) - 1` で最後の要素であることを確認して、`rest_pat` と値の残り（`value[i:]`）を再帰的に `bind()` して `return` します。`(*, [a])` のように `rest_pat` が単純に変数名のときは変数に値の残りがそのまま設定されますが、パターンを指定することもできます。いまのところ、あまり意味のある指定はできませんが・・・

それ以外の場合は `i` が値の要素数（`len(value)`）以上になっていないことを確認し、`i` 番目の要素どうしをマッチさせるため `self.bind(sub_pat, value[i])` を呼びます。`i` が大きすぎたり `bind()` の結果が `False` だったりしたら `False` を返して関数を抜けます。

途中で `return` せずに `for` を抜けたら rest パターンではなかったということなので、パターンの要素数と値の要素数が一致するかどうかを返します。パターンの要素はすべて見終わっているので、要素数が違っているならば値が余ってしまったということです。

動かしてみましょう。

```py
    # Example

    print("Rest pattern:")

    print(toil.ast(r""" def foo(*a) do print(a) end """))
    # -> (define, [foo, (func, [[(*, [a])], (print, [a])])])
    toil.walk(r""" def foo(*a) do print(a) end """)
    toil.walk(r""" foo() """) # -> []
    toil.walk(r""" foo(2) """) # -> [2]
    toil.walk(r""" foo(2, 3) """) # -> [2, 3]

    toil.walk(r""" def foo(a, *b) do print(a, b) end """)
    # toil.walk(r""" foo() """) # -> Pattern mismatch
    toil.walk(r""" foo(2) """) # -> 2 []
    toil.walk(r""" foo(2, 3) """) # -> 2 [3]
    toil.walk(r""" foo(2, 3, 4) """) # -> 2 [3, 4]
```

想定通りの動きです。`def foo(a, *b)` という定義では、少なくとも 1 つは引数が必要なので `foo()` はエラーになります。

```py
    toil.walk(r""" def foo(a, [b, *c]) do print(a, b, c) end """)
    toil.walk(r""" foo(2, [3, 4, 5]) """) # -> 2 3 [4, 5]
```

配列の中にも rest パターンが使えます。

```py
    toil.walk(r""" def foo(a, *[b, c]) do print(a, b, c) end """)
    toil.walk(r""" foo(2, 3, 4) """) # -> 2 3 4
```

rest パターンで変数名ではなく別のパターンを使ったテストです。これだと `def foo(a, b, c)` と定義したのと変わりませんが・・・

```py
    # toil.walk(r""" def foo(*a, b) do print(a, b) end """)
    # toil.walk(r""" foo(2, 3) """) # -> Pattern mismatch
```

パターン末尾以外の部分で `*` を使うとエラーです。ただし呼び出すまではエラーになりません。

```py
    toil.walk(r""" [a, *b] := [2]; print(a, b) """) # -> 2 []
    toil.walk(r""" [a, *b] := [2, 3, 4]; print(a, b) """) # -> 2 [3, 4]
```

分割代入でも使えます。

```py
    toil.walk(r""" for [a, *b] in [[2], [3, 4, 5]] do print(a, b) end """)
    # -> 2 []\n3 [4, 5]
```

for 式でも使えます。

```py
    toil.walk(r"""
        match [2, 3, 4] case [a, *b] then print(a, b) case _ then print("no") end
    """) # -> 2 [3, 4]
    toil.walk(r"""
        match [] case [a, *b] then print(a, b) case _ then print("no") end
    """) # -> no
```

match 式でも使えます。

```py
    toil.walk(r"""
        def quicksort(a) do
            if a.len() <= 1 then a else
                # pivot := a.first(); rem := a.rest();
                [pivot, *rem] := a;
                left := rem.filter(func x do x < pivot end);
                right := rem.filter(func x do x >= pivot end);
                quicksort(left) + [pivot] + quicksort(right)
            end
        end
    """)
    print(toil.walk(r""" quicksort([5, 3, 8, 4, 2]) """)) # -> [2, 3, 4, 5, 8]
```

最後は `quicksort()` の例です。`[pivot, *rem] := a` と書くことにより最初の要素と残りの要素の配列に分けることができます。この操作はわりと重要なので覚えておくといいかも。

`bind()` に機能を追加したことで、関数呼び出し・分割代入・for 式・match 式のすべてで統一的に rest パターンが使えるようになりました。

この調子でさらにパターンを増やしていきます。
