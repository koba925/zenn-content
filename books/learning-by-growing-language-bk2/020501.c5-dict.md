---
title: "5.1　辞書型の導入"
---

タプル、配列、文字列に続き、辞書（dict）を追加します。

辞書は `Environment` で大活躍していて今さら説明不要だと思いますが、キー（Key）と値（Value）をペアにして管理するデータ構造です。配列が 0、1、2 ・・・といった整数の添字で要素を管理するのに対し、辞書では文字列などのキーを使って柔軟にデータを取り出すことができます。ただし、Toil では単純化のためキーは文字列のみとします[^awk-string]。

[^awk-string]: Python に慣れていると制限がきついように感じるかもしれませんがたいていは大丈夫です。プログラミング言語 AWK では、基本的に文字列と連想配列（ここでいう辞書）だけであらゆる処理を行います（必要に応じて数字の並んだ文字列を数として扱う）。これはちょっと極端な例ですが、その影響が残っている言語もあります。

冒頭で `Value` に `dict` を追加したら、組み込み関数を追加します。

```diff py
...

-type Value = None | bool | int | str | Callable | tuple | list
+type Value = None | bool | int | str | Callable | tuple | list | dict

     ...

     def _builtins(self):

         self._env.define(Ident("list"), lambda args: args)
+        self._env.define(Ident("dict"), lambda args: dict(args))
 
         ...

+        self._env.define(Ident("in"), lambda args: args[0] in args[1])
+        self._env.define(Ident("copy"), lambda args: args[0].copy())
+
+        self._env.define(Ident("keys"), lambda args: list(args[0].keys()))

             lambda args: str(args[1]).join(map(str, args[0])))
         ...
```

タプルの `tuple()` や配列の `list()` と同様、辞書の生成には Python の `dict()` をそのまま利用しています。Python の `dict()` は、キーと値のペアの配列（たとえば `[["a", 1], ["b", 2]]`）を渡すと辞書を作ってくれますので、`args` をそのまま渡すとちょうどいいのです。

`in()` は辞書に対して使った場合、指定したキーが辞書に存在するかを返します。辞書以外のコレクションに対しても使えますが、辞書に対しては特に高速に動作し、なくてはならない機能なのでここで導入しました。Python の `in` のように二項演算子にしてもいいのですがここは別のアプローチをとります。あとで。

`copy()` と `keys()` は関数になっている以外 Python の同名のメソッドと同じです。

`items()` もほぼ同じなんですが Python の `items()` がキーと値のペアをタプルで返してきたものを、ペアの配列に変換して返しています。タプルのままでも致命的な影響はないんですが、Toil ではタプルが AST で特別な意味を持っていることや、このあと実装予定のパターンマッチでは配列のほうがすっきり書けることからこうしています。

あと、代入時の型チェックを緩めてやる必要があります。

```diff py
 class Evaluator:
     ...

     def _assign(self, left_expr, right_expr, env):
         val = self.eval(right_expr, env)
         match left_expr:
             ...
             case (Ident("index"), [coll_expr, index_expr]):
                 coll_val = self.eval(coll_expr, env)
                 index_val = self.eval(index_expr, env)
-                assert isinstance(coll_val, list) and isinstance(index_val, int), \
-                    f"Invalid index assignment @ _assign(): {left_expr}"
-                coll_val[index_val] = val
+                match coll_val:
+                    case list() if isinstance(index_val, int):
+                        coll_val[index_val] = val
+                    case dict() if isinstance(index_val, str):
+                        coll_val[index_val] = val
+                    case _: assert False, \
+                        f"Invalid index assignment @ _assign(): {left_expr}"
                 return val
             ...
```

`assert` の中に `and` や `or` で複雑な条件を書くと想定通りに型判定してくれないようなので `match` を使って書き換えています。実は型の警告を出ないようにするためにこうしてるだけで、型ヒントをつけてなければ `coll_val[index_val] = val` だけで動くのは動くんですけどね。

さてこれで辞書が使えるようになっています。

実行例を見てみましょう。

```py
    # Example

    print("Dict:")

    print(toil.walk(r""" dict() """)) # -> {}
    print(toil.walk(r""" dict(["a", 2]) """)) # -> {'a': 2}
    print(toil.walk(r""" d := dict(["a", 2], tuple("b", 3)) """)) # -> {'a': 2, 'b': 3}
```

辞書が作れました。キーと値のペアはタプルでも問題ありません。

```py
    print(toil.walk(r""" index(d, "a") """)) # -> 2
    print(toil.walk(r""" d["b"] """)) # -> 3
```

要素へのアクセスには、すでに実装済みの組み込み関数 `index()`（構文としては `d[key]`）がそのまま使えます。`index` の実装は `lambda args: args[0][args[1]]` で、この形を見れば対象が辞書であっても Python 側がうまくやってくれることがわかります。

```py
    toil.walk(r""" d["b"] = 4 """)
    toil.walk(r""" d["c"] = dict(["d", 5]) """)
    print(toil.walk(r""" d """)) # -> {'a': 2, 'b': 4, 'c': {'d': 5}}
    print(toil.walk(r""" d["c"]["d"] """)) # -> 5
```

辞書要素への代入と、ついでに辞書の入れ子も確かめました。存在しないキーを指定して代入すると新しいキー・値のペアが追加されます。

```py
    print(toil.walk(r""" len(d) """)) # -> 3
    print(toil.walk(r""" pop(d, "c") """)) # -> {'d': 5}
    print(toil.walk(r""" len(d) """)) # -> 2
```

既存の組み込み関数で、辞書に適用可能なものはそのまま使えます。

```py
    print(toil.walk(r""" in("a", d) """)) # -> True
    print(toil.walk(r""" in("A", d) """)) # -> False
    print(toil.walk(r""" in("a", "abc") """)) # -> True
    print(toil.walk(r""" in("A", "abc") """)) # -> False
```

`in()` は辞書以外のコレクションに対しても動きます。

```py
    toil.walk(r""" e := copy(d); e["b"] = 6 """)
    print(toil.walk(r""" d """)) # -> {'a': 2, 'b': 4}
    print(toil.walk(r""" e """)) # -> {'a': 2, 'b': 6}
```

`e` の要素を変更しても `d` の要素が変わらないことから、`e` は `d` とは別の実体を持つコピーだということが確認できます。

```py
    print(toil.walk(r""" keys(d) """)) # -> ['a', 'b']
    print(toil.walk(r""" items(d) """)) # -> [['a', 2], ['b', 4]]
    toil.walk(r""" for key in keys(d) do print(d[key]) end """) # -> 2\n4
    toil.walk(r""" for item in items(d) do print(item) end """) # -> ['a', 2]\n['b', 4]
```

`keys()`、`items()` も動作しました。`for` で使うのが典型的ですね。

```py
    # toil.walk(r""" d := dict(); d[2] = 3 """) # -> Invalid index assignment
```

キーは文字列のみとしましたので、数をキーにしようとするとエラーになります。

ここまですんなりできましたが、辞書の値を作るのに毎回 `dict(["a", 2], ["b", 3])` のように書くのは面倒ですね。あとひとふんばりしましょう。
