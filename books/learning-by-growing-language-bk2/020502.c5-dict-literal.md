title: "5.2 辞書リテラル"
---

`dict(["a", 2], ["b", 3])` ではなく、`{"a": 2, "b": 3}` のように書けるようにしましょう。Python ならそれだけですが、ここだけ JavaScript の流儀を取り入れて、`{"a": 2, "b": 3}` を作るのに以下のように書けるようにします。辞書リテラルについては JavaScript の書き方がうらやましいのです。

- `{"a": 2, "b": 3}`
- `{a: 2, b: 3}`
- （`a := 2`、`b := 3` の状態で）`{a, b}`

主に見た目の修正ですので、字句解析・構文解析が主役です。これも構文糖衣というのかな？

構文解析の段階で辞書が登場しますので `Expr` にも `dict` を追加します。えーとその前提として、AST では辞書を表すのに Python の `dict` を使います、ということを言っておかないとですね。Toil の基本方針です。

```diff py
 type Token = None | bool | int | str | Ident
-type Expr = None | bool | int | str | Ident | tuple | list
+type Expr = None | bool | int | str | Ident | tuple | list | dict
 type Value = None | bool | int | str | Callable | tuple | list | dict
```

`{` と `}` をトークンとして扱います。

```diff py
 class Scanner:
     ...
 
     def tokenize(self) -> list[Token]:
         while (c := self._current_char()) != "$EOF":
             self._start_pos = self._current_pos
             match c:
                 ...
-                case c if c in "+-*/%()[],;":
+                case c if c in "+-*/%()[]{},;":
                     self._tokens.append(Ident(c)); self._advance()
                 ...
```

構文解析はすこし複雑です。すこし複雑なことをしようとしているのですこし複雑になります。

```diff py
 class Parser:
     ...

     def _primary(self) -> Expr:
         match self._current_token():
             ...
             case Ident("["): return self._list()
+            case Ident("{"): return self._dict()
             case Ident("func"): return self._func()
             ...
```

`{` が来たら `_dict()` を呼ぶ。ここはいいですね。

```diff py 
     def _list(self):
         ...
 
+    def _dict(self):
+        def _parse_key_value(dic):
+            match self._current_token():
+                case str():
+                    key = self._current_and_advance()
+                    self._consume(Ident(":"))
+                    dic[key] = self._expression()
+                case Ident(key) if is_ident(key):
+                    self._current_and_advance()
+                    if self._current_token() == Ident(":"):
+                        self._current_and_advance()
+                        dic[key] = self._expression()
+                    else:
+                        dic[key] = Ident(key)
+                case invalid:
+                    assert False, f"Invalid key @ _dict(): {invalid}"
+
+        self._current_and_advance()
+        dic = {}
+        if self._current_token() != Ident("}"):
+            _parse_key_value(dic)
+            while self._current_token() != Ident("}"):
+                self._consume(Ident(","))
+                _parse_key_value(dic)
+        self._consume(Ident("}"))
+        return dic

     def _func(self):
         ...
```

内部関数の `_parse_key_value()` がキモです。`<キー>: <値>` というペアを 1 つ読み込みます。`<値>` というか、正確には値を表す式（`Expr`）ですね。

`case` ごとに見ていきます。

`case str()` は基本のケースで、キーが文字列だった場合です。キーを読み、次が `:` であることを確認したら式を読みこんで辞書の指定されたキーに設定します。

`case Ident(key) if is_ident(key)` は `a: 2` のように書いた場合の処理です。この場合キーは識別子のトークンとして渡されてきます。`if is_ident(key)` は `:` のような記号や `$EOF` がキーとして扱われないようにするためのガードです。キーを読んだ後、`:` が続いていれば `case str()` と同様にして辞書に追加します。`case Ident(key)` とした場合、`key` には文字列が入るので、辞書に追加されたものはキーがもともと文字列だった場合と同じになります。

```py
class Ident:
    __match_args__ = ("name",)

    def __init__(self, name: str) -> None: self.name = name
    ...
```

`:` でなければキー（識別子）を値としても使って辞書に追加します。`{a}` であればキーが `"a"`（`str`）、値（の式）が `a`（`Ident`）になります。これであたかも `{"a": a}` と書いたような AST を作ってくれます。

`_parse_key_value()` がわかれば、`_dict()` の本体は `_comma_separated_exprs()` と同じように理解できます。まず 1 つキーと値のペアを読み込み、次がカンマである間もう 1 つ読む、ということです。

`Evaluator` では `list` と同じように、値を評価して辞書を値にします。

```diff py
 class Evaluator:
     def eval(self, expr: Expr, env: Environment) -> Value:
         match expr:
             case None | bool() | int() | str(): return expr
             case list() as exprs:
                 return [self.eval(expr, env) for expr in exprs]
+            case dict() as exprs:
+                return {key: self.eval(val, env) for key, val in exprs.items()}
             case Ident("return"): raise ReturnException(None)
             ...
```

`{<キー>: <値> for key, val in <辞書>}` は Python の辞書内包表記です。辞書からキーと値のペアを 1 つずつ取ってきて、`<値>` の式を評価し、`<キー>` とペアにして新しい辞書を作ります。

これで修正は終わりです。実行例に進みます。

```py
    # Example

    print("Dict literal:")

    print(toil.walk(r""" {} """)) # -> {}
    print(toil.ast(r""" {"a": 2 + 3} """)) # -> {'a': (add, [2, 3])}
    print(toil.walk(r""" {"a": 2 + 3} """)) # -> {'a': 5}
    print(toil.walk(r""" {"a": 2, "b": 3} """)) # -> {'a': 2, 'b': 3}
    print(toil.walk(r""" {a: 4, b: 5} """)) # -> {'a': 4, 'b': 5}
    print(toil.ast(r""" {a, b} """)) # -> {'a': a, 'b': b}
    print(toil.walk(r""" a := 6; b := 7; {a, b} """)) # -> {'a': 6, 'b': 7}

    print(toil.walk(r""" {a: 8, b: {c: 9}} """)) # -> {'a': 8, 'b': {'c': 9}}

    # toil.walk(r""" { """) # -> Invalid key
    # toil.walk(r""" {2: 3} """) # -> Invalid key
    # toil.walk(r""" {: 3} """) # -> Invalid key
    # toil.walk(r""" {a:} """) # -> Invalid token
    # toil.walk(r""" {a: 2 b: 3} """) # -> Expected ,
    # toil.walk(r""" {a: 2,} """) # -> Invalid key
```

前節では辞書を `dict(["a", 2 + 3])` と書き、`(dict, [['a', (add, [2, 3])]])` という関数呼び出しの AST になりました。本節では `{"a": 2 + 3}` と書けるようにして `{'a': (add, [2, 3])}` と Python の辞書を使った AST に変換しました。評価したものはどちらも `{'a': 5}` という値になっています。辞書リテラルも一種の構文糖衣と言えるかもしれません。`{a, b}` と書いて `{'a': a, 'b': b}` という AST になるのも人間のための略記法ですね。
