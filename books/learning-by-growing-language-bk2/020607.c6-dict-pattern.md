title: "6.7 辞書パターン"
---

次は辞書パターンです。

`{"aa": a, "bb": b} := {"aa": 2, "bb": 3}` と書けば `a` に `2`、`b` に `3` が入るようにします。また、パターンでも `{"a": a, "b": b}` のような形なら代わりに省略した書き方の `{a, b}` を使うこともできます。

rest パターンにも対応します。`match {"aa": 2, "bb": 3} case {"aa": a, *r} then ... end` と書けば、マッチした `"aa"` 以外の要素が `r` に入ります。

`*r` というパターンの構文解析は単項演算子としては実装済みですが、ここでは辞書のキーの位置に現れますので `_dict()` の修正が必要です。もう少し細かく言うと内部関数の `_parse_key_value()` の中ですね。

```diff py
 class Parser:
     ...

     def _dict(self):
         def _parse_key_value(dic):
             match self._current_token():
+                case Ident("*"):
+                    self._current_and_advance()
+                    dic["*"] = self._current_and_advance()
                 case str():
                     key = self._current_and_advance()
                     self._consume(Ident(":"))
                     dic[key] = self._expression()
                 ...
 
         self._current_and_advance()
         ...
```

キーに当たる箇所に `*`（`Ident("*")`）が出てきたら rest パターンとみなして処理します。もうひとつトークンを読むと変数名が入っているはずなので、`"*"` をキー、今読んだ変数名を値として辞書に追加します。意味的には `"*"` はキーではないし変数名も値ではないのですが、これで単純に書けるのでそうしています[^stick-to-meaning]。

[^stick-to-meaning]: 意味にこだわるならキーを `("*", <変数名>)`、値は `None` にでもしておくのかな？


`bind()` の修正です。

```diff py
 class Environment:
     ...

     def bind(self, pattern: Expr, value: Value) -> bool:
         match pattern:
             ...
             case (Ident("tuple"), sub_pats):
                 return isinstance(value, tuple) and self._bind_seq(sub_pats, value)
+            case dict():
+                return isinstance(value, dict) and self._bind_dict(pattern, value)
             case _:
                 return type(pattern) is type(value) and pattern == value
 
     ...

+    def _bind_dict(self, pattern, value):
+        tmp_pat, tmp_val = pattern.copy(), value.copy()
+
+        rest_pat = tmp_pat.pop("*", None)
+
+        for key, sub_pat in tmp_pat.items():
+            if key not in tmp_val or not self.bind(sub_pat, tmp_val.pop(key)):
+                return False
+
+        if rest_pat is not None: return self.bind(rest_pat, tmp_val)
+        return True
```

大枠から説明すると、`pattern` に含まれるキーと一致する `value` 側の値を探し、パターンをマッチさせながら `value` からそのキー・値を削除していきます。rest パターンが指定されていた場合は `pattern` 側のキーをすべて処理したあとで `value` 側に残った値を rest パターンの変数名に `bind()` します。rest パターンが指定されていなければ値が残っていても何もしません。エラーにもしません[^design-decision]。

[^design-decision]: ここは設計上の選択肢で、値が残っていたらエラーにするというのもあり得ます。その場合はキーをすべて指定するか、そうしないなら必ず rest パターンを指定する必要があります。Toil は全体的にユルい言語なのでここもユルくしました。

このように、キーを削除しながら処理を行いますが、本物の辞書値からキーを削除してしまっては困るので、`tmp_pat`、`tmp_val` という変数にいったんコピーを作り、コピー側で作業します。

`tmp_pat.pop("*", None)` は辞書 `tmp_pat` からキー `"*"` に対応する値を取得して返し、同時にそのキーを辞書から削除します。もしキー `"*"` が存在しなければ `None` を返します。言葉で書くより Python で書いたほうがわかりやすそうですね。これと同じ意味です。

```py
if "*" in tmp_pat:
    rest_pat = tmp_pat["*"]; del tmp_pat["*"]
else:
    rest_pat = None
```

for ループでは、`tmp_pat` に含まれるそれぞれのキー・値のペアについて、キーが存在すればマッチさせています。キーが存在しなかったりマッチで失敗したら `False` を返します。

ループを抜けたあと、もし `rest_pat` が `None` でなければ、つまり rest パターンが指定されていれば、rest パターンに指定された変数名（`rest_pat`）と `tmp_val` をマッチさせます。`tmp_val` に何も残っていない、つまり `{}` になってしまっていてもそのままマッチさせます[^why-bind]。

[^why-bind]: 変数名しか入らないはずなのに `define()` ではなくわざわざ `bind()` でマッチさせているのは誤って変数名以外が入っていた時に `bind()` の方が適切にエラーを処理してくれるからです。変数名なのに `rest_name` などとせず `rest_pat` としているのは `bind()` に渡しているからというだけの理由です。

実行例に進みます。

```py
    # Example

    print("Parameter match:")

    print(toil.ast(r""" def foo(a, {"bb": b, "cc": c}) do print(a, b, c) end """))
    # -> (define, [foo, (func, [[a, {'bb': b, 'cc': c}], (print, [a, b, c])])])
```

AST の確認。パターン内でも辞書の値をそのまま使います。

```py
    toil.walk(r""" def foo(a, {"bb": b, "cc": c}) do print(a, b, c) end """)
    toil.walk(r""" foo(2, {"bb": 3, "cc": 4}) """) # -> 2 3 4
```

できました。

```py
    print(toil.ast(r""" def foo(a, {b, c}) do print(a, b, c) end """))
    # -> (define, [foo, (func, [[a, {'b': b, 'c': c}], (print, [a, b, c])])])
    toil.walk(r""" def foo(a, {b, c}) do print(a, b, c) end """)
    toil.walk(r""" foo(3, {b: 4, c: 5}) """) # -> 3 4 5
```

省略形も使えます。すっきりしますね。

```py
    # toil.walk(r""" foo(2, [3, 4]) """) # -> Pattern mismatch

    # toil.walk(r""" foo(3, {b: 4, d: 5}) """) # -> Pattern mismatch
    # toil.walk(r""" foo(3, {b: 4}) """) # -> Pattern mismatch
    toil.walk(r""" foo(3, {b: 4, c: 5, d: 6}) """) # -> 3 4 5
```

エラーの確認ですが、値の側に余りがあるときだけはエラーになりません。余ったキーは無視されます。

```py
    print("Destructuring bind:")

    toil.walk(r""" {a, b} := {a: 2, b: 3}; print(a, b) """) # -> 2 3
    # toil.walk(r""" {a, b} := 2 """) # -> Pattern mismatch
    # toil.walk(r""" {a, b: [c, d]} := {a: 2, b: 3} """) # -> Pattern mismatch
```

分割代入。

```py
    print(toil.ast(r""" {a, *r} := {a: 3} """))
    # -> (define, [{'a': a, '*': r}, {'a': 3}])
    toil.walk(r""" {a, *r} := {a: 3}; print(a, r) """)
    # -> 3 {}
    toil.walk(r""" {a, *r} := {a: 3, b: 4}; print(a, r) """)
    # -> 3 {'b': 4}
    toil.walk(r""" {a, *r} := {a: 3, b: 4, c: 5}; print(a, r) """)
    # -> 3 {'b': 4, 'c': 5}
```

rest パターンも動きます。なんとなく気分で分割代入のところに入れましたが関数呼び出しでも rest パターンは使えますのでご安心ください。

```py
    toil.walk(r"""
        {a, b: {c, d}} := {a: 2, b: {c: 3, d: 4}};
        print(a, c, d)
    """) # -> 2 3 4
```

辞書が入れ子になっても大丈夫。この場合、`b` はキーでしかないので `b` という変数に `{c: 3, d: 4}` が入ったりはしません。

```py
    print("Destructuring bind (for):")

    print(toil.walk(r"""
        a := [];
        for {i, j} in [{i: 2, j: 3}, {i: 4, j: 5}] do a.push([i, j]) then a end
    """)) # -> [[2, 3], [4, 5]]
    # toil.walk(r""" for {i, j} in [2, 3] do None end """) # -> Pattern mismatch
```

for 式も問題なし。

```py
    print("Match:")

    print(toil.walk(r"""
        match {a: 2, b: 3} case {a, b} then a * b case _ then "no" end
    """)) # -> 6
    print(toil.walk(r""" [a, b] """)) # -> [2, 3]
    print(toil.walk(r"""
        match {a: 4, c: 5} case {a, b} then a * b case _ then "no" end
    """)) # -> no
    print(toil.walk(r""" [a, b, _] """)) # -> [4, 3, {'a': 4, 'c': 5}]
    print(toil.walk(r""" match 2 case {a, b} then a * b end """)) # -> None
```

match 式でも使えます。

省略形や入れ子、rest パターンに対応した辞書パターンができました。これでコレクションのパターンマッチがひと通りそろったことになります。

あとちょっと付け足してパターンの追加にひと区切りをつけます。
